# Fable Fox

Веб-витрина, каталог и система управления авторскими 3D-моделями, миниатюрами, кубиками и другими атрибутами для настольных ролевых игр.

Проект находится на стадии предпроектной подготовки. Визуальные референсы задают направление: тёмное фэнтези, глубокий сине-чёрный фон, тёплые золотые акценты, крупные изображения изделий и редакционная подача бренда.

## Предварительный стек

- Vite + React + TypeScript для публичного сайта и админ-панели
- React Router
- CSS Modules или обычный CSS с дизайн-токенами
- отдельный backend API, база данных и файловое хранилище
- защищённая аутентификация и ролевая модель доступа
- Vitest и Testing Library
- Playwright для ключевых пользовательских сценариев

Конкретный backend-стек, способ оформления заказа и инфраструктура будут выбраны после уточнения бизнес-процесса заказчика. Наличие API и админ-панели является обязательным требованием MVP.

## Принципы проекта

- Сначала проверяем ценность витрины и каталога, затем усложняем коммерческую часть.
- Контент и товары не должны быть жёстко зашиты в компоненты.
- Мобильная версия проектируется одновременно с десктопной.
- Атмосферность не должна ухудшать читаемость, скорость загрузки и доступность.
- Решения и изменения требований фиксируются в документации.
